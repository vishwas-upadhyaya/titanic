# Titanic Survival Prediction

## Project Overview
This repository contains a comprehensive analysis and predictive modeling project based on the Titanic dataset, a classic entry-point for data science and machine learning. The primary objective is to build a model that predicts whether a passenger survived the Titanic shipwreck based on various features such as age, gender, socio-economic status, and more.

## What is this Project?
The project involves several Jupyter Notebooks that document the data science workflow:
- **Data Acquisition:** Loading the training and testing datasets from CSV files.
- **Exploratory Data Analysis (EDA):** Visualizing data distributions and identifying correlations between features (like `Pclass`, `Sex`, and `Age`) and survival rates.
- **Data Preprocessing:** Handling missing values in columns like `Age`, `Cabin`, and `Embarked`, and converting categorical variables into numerical formats suitable for machine learning models.
- **Modeling:** Training various classification algorithms to predict survival.
- **Submission:** Generating a `submission.csv` file containing the predictions for the test set.

## Why it was done?
This project was created to:
- Demonstrate proficiency in Python's data science ecosystem (`Pandas`, `NumPy`).
- Practice common data cleaning and feature engineering techniques.
- Explore the impact of different features on the likelihood of survival in a historical context.

## Tech Stack
- **Language:** Python
- **Libraries:**
  - **Pandas:** For data manipulation and analysis.
  - **NumPy:** For numerical computations.
  - **Matplotlib / Seaborn:** For data visualization and EDA.
  - **Jupyter Notebook:** For interactive development and documentation.

## File Structure
- `titanic_train.csv`: The training data with labels (survived or not).
- `titanic_test.csv`: The test data without survival labels.
- `analysis1.ipynb`: The primary notebook containing detailed data analysis and preprocessing steps.
- `analysis.ipynb` & `titanic_analysis.ipynb`: Alternative versions or stages of the analysis.
- `submission.csv`: The final prediction output generated by the model.
- `gender_submission.csv`: A sample submission file provided by Kaggle for reference.
